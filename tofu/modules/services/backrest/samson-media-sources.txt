# What samson backs up out of /export/media, one path per line, RELATIVE TO THE
# MOUNT ROOT -- so `media/live`, not `/data/media/live`.
#
# Relative because the root differs per tool: kopia mounts at /data, backrest at
# /backup, and both read this file while they run in parallel. Encoding one of
# them here meant the other had to rewrite the prefix, and the obvious way to do
# that is a trap:
#
#   replace(line, "/data/", "/backup/")
#
# OpenTofu treats a SLASH-WRAPPED substring as a REGEX, so that pattern is
# `data` and the result is `//backup//media/live`. Fifty paths that do not
# exist, and restic would have happily backed up nothing. Caught in a render
# check on 2026-09-26; the roots are prepended in ../../../main.tf instead.
#
# The media library is 8.4 TB and the Storage Box has 4.5 TB free, so the
# directory itself is never snapshotted -- only these. The selection is a
# deliberate choice about what is worth off-site, not a consequence of how the
# folders are arranged.
#
# This lived in policies.json until 2026-09-25, as 48 empty policy objects that
# existed only to be a list. A policy that says nothing is indistinguishable
# from no policy at all -- kopia inherits (global) either way -- so they were
# noise in a file where every other line is load-bearing.
#
# Blank lines and # comments are ignored. A path here with no matching
# directory on the array shows up as a bootstrap FAILED line in kopia's logs.
